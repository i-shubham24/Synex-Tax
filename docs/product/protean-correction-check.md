# Protean Correction Formats Verification Report

Specification Version: 1.2
Date: 4 August 2026
Applicable Standards: Forms 138 (Q1 to Q3), 140, 143, 144
Scope: C1, C2, C3, C5, C9 Correction Statements

## Executive Summary

SynexTax TDS and TCS correction engine in packages/tax-engine/src/tds/correction.ts has been cross-checked field by field against the official Protean (formerly NSDL) correction spreadsheets. All 23 regression test suites pass with exact positional and field count alignment.

## Form and Record Structure

The correction file format is caret-separated (^), ending with Windows CRLF (\r\n). Each file contains four structural record types with strictly enforced field counts:

1. FH (File Header): 18 fields. Top-level metadata and batch hashes.
2. BH (Batch Header): 72 fields. Deductor details and token links.
3. CD (Challan Detail): 30 fields. Challan BSR, date, and tax amounts.
4. DD (Deductee Detail): 45 fields. Payee PAN, amounts, and certificates.

## Form Coverage Matrix

### 1. Form 138 (Salary, Quarters 1 to 3)
* FH Field 18: Mandatory consolidated file hash. Must match the hash in the original TRACES conso file.
* BH Field 4: Blank on C1; reflects valid challan count for C2, C3, C5, and C9.
* DD Field 12: Dropped in salary corrections.
* DD Field 28: No tax rate for salary rows in Q1 to Q3.
* Quarter 4 Note: Annexure II format for Q4 has not yet been released by Protean; official portal link routes back to the downloads index.

### 2. Form 140 (Non-Salary Domestic)
* FH Field 18: Must be left blank per specification.
* C1 Deductor Update: Carries fields 15 to 30, 32 to 45, 54, 57 to 59, 68, and 69. Fillers and unused fields are explicitly stripped.
* C2 Challan Update: Batch Updation Indicator (BH field 7) is 1 when deductor info is folded, 0 otherwise.
* C3 Deductee Update: Challan values remain synced with total payee deposited amounts.
* C5 PAN Correction: Validates old PAN against new PAN. BH field 13 (TAN) and BH field 47 (Batch Total) are left blank.
* C9 Addition: Fully supported with new challans and mapped deductees. Nil challans dated at quarter-end.

### 3. Form 143 (TCS)
* Deductee / Collectee DD field 28 carries no rate.
* Collection codes and PAN validations verified.

### 4. Form 144 (Non-Resident Remittances)
* FH Field 18: Mandatory consolidated file hash.
* DD Field 12: Carries deductee status code.
* Remittance country and DTAA rate fields verified.
